Android Emotion Mission App

기쁜데 슬프다 앱 작동 설명

이 앱은 사용자가 그룹별로 주어진 오늘의 감정 조합을 얼굴 표정으로 표현하고, 온디바이스 AI 분석 결과와 목표 감정의 유사도를 점수화한 뒤 그룹 피드와 기록 화면에 저장하는 Android 앱입니다.

앱의 핵심 목적

매일 그룹마다 다른 감정 미션이 생성됩니다. 사용자는 셀피를 촬영하거나 갤러리 이미지를 선택하고, 앱은 사진 속 얼굴 수를 검사한 뒤 감정 분포를 분석합니다. 분석된 감정 분포가 오늘의 목표 감정 조합과 가까울수록 높은 점수를 받습니다.

전체 작동 흐름

1. 그룹 선택MainActivity에서 참여할 그룹과 오늘의 목표 감정을 확인
2. 사진 제출카메라, 갤러리, 테스트용 프리셋 중 하나를 선택
3. 얼굴 검증ML Kit으로 얼굴이 정확히 1명인지 검사
4. 감정 분석TFLite 모델 또는 프리셋으로 7개 감정 확률 계산
5. 저장/공유점수와 위치를 Room DB 및 그룹 피드에 저장

사진 분석과 점수 계산

1. 얼굴 검증

사용자가 실제 사진을 넣으면 ML Kit Face Detection으로 얼굴 수를 셉니다. 얼굴이 0명 또는 2명 이상이면 업로드가 막히고, 정확히 1명일 때만 감정 분석을 진행합니다.

2. 감정 분류

emotion_mobilenetv2.tflite 모델을 불러와 이미지를 96x96 RGB 입력으로 변환한 뒤 7개 감정 확률을 계산합니다. 테스트 프리셋을 고르면 선택한 감정을 강제로 우세하게 만든 결과를 사용합니다.

점수 공식은 목표 감정 벡터와 실제 감정 벡터 사이의 유클리드 거리를 사용합니다. 거리가 가까울수록 점수는 100점에 가까워지고, 멀수록 낮아집니다.

예시 감정 결과

HAPPY 45%, SAD 42%, NEUTRAL 13%처럼 감정별 확률이 합계 100%가 되도록 정규화됩니다.

그룹 기능

참여 및 생성

기본 그룹은 코드에 포함되어 있으며, 사용자는 초대 코드를 입력해 그룹에 참여하거나 새 그룹 이름과 코드를 입력해 새로운 채널을 만들 수 있습니다.

피드 및 랭킹

제출된 미션 결과는 그룹 피드에 추가됩니다. 랭킹 탭은 같은 그룹의 제출 기록을 점수순으로 정렬해 보여줍니다.

테스트와 시연 포인트

  1. 홈 화면에서 그룹을 선택하면 오늘의 목표 감정 조합이 바뀝니다.
  2. 미션 화면에서 카메라, 갤러리, 테스트 프리셋 중 하나를 선택합니다.
  3. 얼굴이 정확히 1명인 경우에만 분석 버튼이 정상 진행됩니다.
  4. 결과 화면에서 점수와 감정 분포를 확인하고 위치를 선택한 뒤 저장합니다.
  5. 그룹 피드에서 내 제출 결과가 추가되고, 랭킹과 아카이브에서도 확인됩니다.

현재 원격 Firebase 서버를 실제로 쓰는 구조가 아니라 FirebaseRemoteMock으로 로컬에 시뮬레이션합니다. 그래서 네트워크 없이도 과제 시연 흐름을 확인할 수 있습니다.
