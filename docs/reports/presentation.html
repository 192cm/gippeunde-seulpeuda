P.2 어플리케이션 개요

기쁜데 슬프다: AI 감정 셀카 미션 SNS

본 프로젝트는 사용자가 매일 제시되는 목표 감정 조합에 맞춰 셀피를 촬영하고, 얼굴 검증과 머신러닝 감정 분석을 거쳐 점수를 산출하는 Android 앱이다. 단순한 사진 업로드가 아니라 표정을 데이터로 분석하여 미션 점수, 그룹 피드, 랭킹, 아카이브로 연결하는 감정 기반 미션 플랫폼을 목표로 한다.

핵심 목표HAPPY, SAD, ANGRY, SURPRISED 감정 비율을 목표 조합과 비교해 0~100점으로 정량화
차별점온디바이스 추론, 얼굴 1명 검증, 위치 태그, 그룹별 미션 공유를 하나의 흐름으로 통합

얼굴 1명 검증
감정 분석 및 점수 계산
결과 저장 / 피드 공유

사용자 경험

  • 그룹과 날짜에 따라 목표 감정 조합 생성
  • 분석 결과가 목표에 가까울수록 높은 점수 부여
  • 결과 화면에서 사진, 감정 비율, 점수, 피드백 확인

분석 및 기술 흐름

  • ML Kit Face Detection으로 얼굴 1명 여부 확인
  • TensorFlow Lite 모델로 네 가지 감정 비율 추론
  • Google Maps, Gemini, 역지오코딩 API와 연동

저장과 소셜 확장

  • Room DB에 날짜, 사진 경로, 감정 결과, 점수 저장
  • FirebaseRemoteMock으로 그룹, 피드, 초대 코드 구성
  • 랭킹과 아카이브로 결과 활용 범위 확장

P.5 어플리케이션 안정성 확보 구현 내용

어플리케이션 안정성 확보 구현 명세

예외 처리
  • Retrofit API 호출 실패 시 기본 문구 / 핫스팟명으로 폴백
  • TFLite 모델 로드 · 추론 실패 시 휴리스틱 분석으로 대체
  • Room 저장과 피드 전송 실패는 토스트로 안내
Null 안정성
  • nullable 타입, 세이프콜, 엘비스 연산자로 기본값 보장
  • JSON 파싱 실패 시 emptyMap() 사용
  • 좌표 / 주소 미확보 시 기본 위치명으로 폴백
생명주기 대응
  • lifecycleScope로 Activity 소멸 시 코루틴 자동 취소
  • collectAsStateWithLifecycle로 Flow 안전 구독
  • remember, LaunchedEffect(key)로 재실행 제어
스레딩 / 메모리
  • DB, 네트워크, 모델 작업은 Dispatchers.IO에서 수행
  • 사진 다운샘플링으로 OOM 방지
  • EXIF 회전 보정으로 세로 셀피 분석 안정화
권한 / 외부환경
  • 카메라 · 위치 권한 거부 시 대체 경로 제공
  • 얼굴 0명 / 2명 이상이면 업로드 차단
  • 오프라인 시 플레이스홀더와 기본값 사용

P.6 기타 사항

프로젝트 차별점과 최종 검증

자체 학습한 감정 분석 모델

FER2013 데이터셋 기반으로 감정 분류 모델을 학습하고, best Keras checkpoint를 TFLite로 변환해 Android assets에 탑재하였다.

앱 기능으로 연결된 ML

얼굴 검증, 감정 비율 추론, 목표 감정과의 비교, 0~100점 산출까지 하나의 미션 흐름으로 연결하였다.

훈련 파이프라인

FER2013 입력을 전처리한 뒤 Conv2D, MaxPooling, BatchNormalization, Dropout 블록과 Dense layer를 거쳐 4개 감정 Softmax로 분류한다.

비율 기반 점수화

네 가지 감정 값을 비율로 분석해 단순 성공 / 실패가 아니라 목표 감정에 얼마나 가까운지 수치화하였다.

그룹 기반 미션 시스템

그룹마다 날짜별 목표 감정 조합이 다르게 생성되며, 사용자는 같은 그룹 안에서 결과를 공유하고 비교할 수 있다.

결과 활용 확장

미션 결과를 그룹 피드, 랭킹, 아카이브로 확장해 개인 점수 확인을 넘어 소셜 미션 플랫폼 형태로 구성하였다.

느낀 점
안준영1학기 내내 수업에서 배운 여러 요소들, Jetpack이나 Coroutine을 직접 사용한 앱을 만들 수 있어 좋았습니다. 특히, 머신러닝 모델을 직접 넣어서 앱을 만드는 좋은 경험을 할 수 있었던 것 같습니다.
장건호아이디어 기획부터 모델 훈련, 안드로이드 앱 구현까지 과정을 처음부터 끝까지 진행해볼 수 있는 뜻 깊은 경험을 한 것 같아서 등록금이 아깝지 않습니다.
