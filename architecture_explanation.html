PPT p.2

서비스 컨셉

Gippeunde Seulpeuda는 그룹별로 매일 다른 목표 감정 조합을 만들고, 사용자가 셀피로 그 감정을 표현하면 AI가 결과 감정을 분석해 점수화하는 감정 미션 앱입니다.

주요 사용자 경험

사용자는 그룹을 선택하고, 오늘의 감정 미션을 확인한 뒤, 카메라 또는 갤러리 사진으로 도전합니다. 결과는 점수와 감정 벡터로 표시되고 그룹 피드에 공유됩니다.

기술적 차별점

ML Kit으로 얼굴 수를 검증하고, 직접 학습한 MobileNetV2 기반 TFLite 모델로 4개 감정 확률을 온디바이스에서 추론합니다.

1. 그룹 선택그룹 ID와 날짜를 기준으로 오늘의 목표 감정 조합 생성
2. 사진 입력카메라 촬영 또는 갤러리 앱에서 이미지 선택
3. 얼굴 검증정확히 1명의 얼굴만 제출 가능하도록 검사
4. 감정 채점목표 벡터와 예측 벡터 거리 기반 점수 계산
5. 저장/공유Room DB와 mock 그룹 피드에 결과 저장

추가 득점 기능 구현 명세

PPT p.4에는 평가표의 가산 항목을 기능별로 묶어 제시합니다.

PPT p.4
평가 항목 예상 점수 구현 근거 발표 문장
Coroutine 20점 ResultActivity.kt의 CoroutineScope(Dispatchers.IO).launch, withContext(Dispatchers.Main), ArchiveActivity.kt의 LaunchedEffect/delay DB 저장과 UI 복귀는 IO/Main Dispatcher로 분리하고, 아카이브 슬라이드쇼는 Coroutine 기반으로 자동 진행됩니다.
외부 APP 연동 20점 ActivityResultContracts.GetContent()로 갤러리 앱에서 이미지 선택 사용자는 카메라 촬영뿐 아니라 Android 갤러리 앱과 연동해 이미지를 가져올 수 있습니다.
DB 30점 Room, MissionRecord, MissionRecordDao, AppDatabase, MissionRepository 미션 날짜, 사진 경로, 목표/결과 감정 JSON, 점수, 위치 좌표를 내부 DB에 저장합니다.
머신러닝 50점 training/train_mobilenetv2_fer2013.py, emotion_mobilenetv2.tflite, FaceAndEmotionAnalyzer.kt FER2013 데이터로 MobileNetV2를 학습하고 TFLite로 변환하여 앱 내부에서 4개 감정 확률을 추론합니다.
API/라이브러리 활용 시연 판단 ML Kit Face Detection, Google Play Services Location, TensorFlow Lite 얼굴 검증과 위치 태깅은 Google/Android 라이브러리와 연동되어 앱 기능을 보강합니다.
PPT에는 “가산점 후보”를 과장하기보다, 실제 동작 화면과 코드 파일명을 함께 보여주는 것이 설득력 있습니다. 특히 DB와 ML은 구현 근거가 명확하므로 핵심 득점 항목으로 앞세우는 것이 좋습니다.

안정성 확보를 위한 구현 내용

PPT p.5는 안정성 항목 평가에 직접 참고되는 페이지입니다.

PPT p.5

입력 안정성

  • 카메라 권한이 없을 때 권한 요청 및 거부 Toast 안내
  • 갤러리 이미지 로딩 실패 시 예외 처리와 사용자 안내
  • 사진이 없거나 얼굴 수가 1명이 아니면 분석/업로드 차단
  • 에뮬레이터 시연을 위한 preset 입력 제공

AI 추론 안정성

  • ML Kit 얼굴 검출 실패 시 -1 상태로 처리
  • TFLite 모델 로딩 실패 시 fallback 감정 분석 로직으로 앱 중단 방지
  • 감정 확률을 4개 라벨 기준으로 정규화하여 점수 계산 일관성 유지
  • 점수는 0..100 범위로 보정

저장 안정성

  • Room DB 싱글턴 생성으로 중복 인스턴스 방지
  • DB insert는 Dispatchers.IO에서 실행
  • 그룹 피드는 SharedPreferences + Moshi JSON으로 mock 저장
  • 저장 완료 후 MainActivity로 복귀해 흐름을 명확히 종료

시연 안정성

  • 카메라가 불안정한 환경에서도 갤러리와 preset으로 동일 흐름 시연 가능
  • Archive 자동 슬라이드쇼는 1~6초 범위 slider로 속도 제어
  • 그룹 생성/참여 입력값 길이 검사
  • 테스트 태그가 있어 UI 테스트 확장 가능
안정성 발표 문장: “실제 평가 환경에서 카메라, 권한, 모델 로딩, DB 저장 중 어느 한 부분이 실패하더라도 앱이 즉시 종료되지 않도록 fallback과 사용자 안내를 넣었습니다.”

PPT p.6

완성도
